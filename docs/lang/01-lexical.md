# 1. 字句構文

## 1.1 拡張子・エンコーディング
- ソースファイル：`.vln`
- エンコーディング：UTF-8
- 改行：LF / CRLF 両方受容、正規化はツール任意
- 先頭の UTF-8 BOM（U+FEFF）はレキサーが黙って除去する。BOM の有無はトークン列に影響しない

## 1.2 キーワード

### 通常キーワード

識別子として使用不可。すべてレキサーが無条件に専用トークンとして消費する。

```
fn let mut self return
if else match
class data enum trait impl
pub internal private
open abstract sealed override
package import
for in while loop break continue
true false
as safe unsafe ref annotation typealias newtype type
inline reified
```

> **注意:** `data` と `reified` はコンテキストキーワードではない。レキサーは出現位置に関係なくこれらを専用トークン（`Data`・`Reified`）として字句解析する。

### 予約キーワード（将来用）

識別子として使用不可。レキサーは専用トークンを生成するが、パーサーは現在これらを受理しない。

```
suspend async await yield
```

### JVM 予約語

Valen では構文上使用しないが、JVM との互換性のため識別子としても使用不可。

```
static void this super null
throw try catch finally extends implements
```

`new` は Valen のキーワードではなく、識別子として使用可能。レキサーは `new` を認識するが `Ident("new")` にマッピングする。

### `as` キーワードの用途

`as` は以下の2つの用途で使用する。

1. **import alias:**
   ```valen
   import java.util.HashMap as HMap;
   ```

2. **型キャスト式（§3, §8 参照）:**
   ```valen
   let x: Long = 42 as Long;                    // 安全な widening
   let pos: Position = unsafe { obj as Position }; // ダウンキャストは unsafe 必須
   ```

### `unsafe` / `ref` キーワードの用途

- `unsafe` — 安全性保証を bypass するブロック式・関数修飾子（§8.5 参照）
- `ref` — `ref mut` でミュータブル参照を作成する（§2.8 参照）。`ref` 単体では使用しない

**Valen 仕様で使わないキーワード:** `static` は導入しない。instance method と associated function の区別は `self` レシーバの有無のみで行う（§5.1 参照）。

| トークン | 記号 | 説明 |

### 字句解析の優先順位

3 文字トークン (`===`, `!==`, `..=`) → 2 文字トークン (`==`, `!=`, `..`, `->`, `=>`, `<=`, `>=`, `<<`, `>>`, `&&`, `||`, `|>`, `::`, `+=`, `-=`, `*=`, `/=`, `%=`) → 1 文字トークンの順に最長一致でマッチする。

## 1.4 リテラル

### 真偽値リテラル

`true` と `false` は `Bool` 型のリテラル。レキサーは `BoolLit(true)` / `BoolLit(false)` トークンを生成する。

```valen
let a = true;   // Bool
let b = false;  // Bool
```

### 整数リテラル

整数リテラルは 10 進のほか、16 進・2 進・8 進のプレフィクス表記をサポートする。
アンダースコア (`_`) による桁区切りが可能。

| 基数 | プレフィクス | 例 | 型 |
|------|-------------|------|------|
| 10 進 | なし | `42`, `1_000_000` | `Int` |
| 16 進 | `0x` / `0X` | `0xFF`, `0x1A_2B` | `Int` |
| 2 進 | `0b` / `0B` | `0b1010`, `0b1111_0000` | `Int` |
| 8 進 | `0o` / `0O` | `0o77`, `0o755` | `Int` |

`L` / `l` サフィックスを付けると `Long` 型になる。すべての基数でサフィックスを使用できる。

```valen
let a = 0xFF;         // Int: 255
let b = 0xFFL;        // Long: 255
let c = 0b1010;       // Int: 10
let d = 0o77;         // Int: 63
let e = 0o77L;        // Long: 63
```

> **内部表現:** レキサーは整数リテラルを i64 として内部保持する。`Int` 型（i32 範囲: -2,147,483,648 〜 2,147,483,647）への制約は型検査フェーズで行われ、レキサーレベルでは i64 範囲まで受容する。i64 範囲を超えるリテラルはレキサーエラーとなる。

### 浮動小数点リテラル

浮動小数点リテラルは小数点 `.` を含む数値。アンダースコア (`_`) による桁区切りが可能。
科学記法（`e` / `E` + 指数）もサポートする。

| サフィックス | 型 | 内部表現 | 例 |
|-------------|------|---------|------|
| なし | `Double` | f64 | `1.0`, `3.14`, `1_000.5`, `1.5e10`, `2.0E-3` |
| `f` / `F` | `Float` | f32 | `1.0f`, `3.14F`, `2.5e3f` |

```valen
let pi = 3.14;           // Double (f64)
let rate = 1_000.5;      // Double (f64)
let sci = 1.5e10;        // Double (f64): 科学記法
let neg = 2.0E-3;        // Double (f64): 負の指数
let half = 0.5f;         // Float (f32)
```

> **注意:** 小数点の前後に少なくとも 1 桁の数字が必要。`.5` や `1.` は不正。`1.0` のように書くこと。

### 文字リテラル

単一引用符で囲んだ 1 文字。エスケープシーケンスをサポートする。

```valen
let a = 'A';
let newline = '\n';
let nul = '\0';
```

**エスケープシーケンス:**

| シーケンス | 文字 |
|-----------|------|
| `\n` | 改行（LF） |
| `\t` | タブ |
| `\r` | 復帰（CR） |
| `\\` | バックスラッシュ |
| `\'` | 単一引用符 |
| `\0` | NUL |

上記以外のバックスラッシュ + 文字の組み合わせ（`\x` など）は、そのまま後続文字として解釈される（将来厳密化の可能性あり）。

### 文字列リテラル

二重引用符で囲んだ文字列。エスケープシーケンスをサポートする。

```valen
let hello = "Hello, world!";
let escaped = "line1\nline2";
let quoted = "She said \"hi\"";
```

**エスケープシーケンス:**

| シーケンス | 文字 |
|-----------|------|
| `\n` | 改行（LF） |
| `\t` | タブ |
| `\r` | 復帰（CR） |
| `\\` | バックスラッシュ |
| `\"` | 二重引用符 |
| `\0` | NUL |

上記以外のバックスラッシュ + 文字の組み合わせ（`\x` など）は、バックスラッシュと後続文字がそのまま残る（将来厳密化の可能性あり）。

### 文字列補間（f-string）

`f"..."` で文字列補間リテラルを記述する。`{expr}` の位置に式を埋め込める。

```valen
let name = "Alice";
let msg = f"Hello, {name}!";           // "Hello, Alice!"
let calc = f"1 + 2 = {1 + 2}";         // "1 + 2 = 3"
```

エスケープ: `\{` / `\}` でリテラルの `{` / `}` を記述。

**制限:** 補間式内でブロック式 `{ ... }` やネストした f-string は使用不可。変数参照、フィールドアクセス、メソッドチェーン、二項演算などの単純な式を使用すること。

> **字句解析上の実装:** レキサーは識別子 `f` の直後に `"` が続く場合、f-string として特別なスキャンモードに入る。`f` と `"` の間にスペースがあると通常の識別子 + 文字列として解析される。

## 1.5 識別子

- パターン: `[a-zA-Z_][a-zA-Z0-9_]*`
- 型は PascalCase（`UserProfile`、`Shape`）
- 関数・メソッド・変数は camelCase（`findUser`、`myValue`）
- パッケージは lowercase.dot（`com.example.app`）
- snake_case を使うとコンパイラが warning を出す（エラーにはならない）
- `_` 単体はワイルドカード用の専用トークン (`Underscore`) として識別子とは区別される

## 1.6 コメント

```valen
// 単行コメント
/* ブロックコメント */
/// ドキュメントコメント（将来 rustdoc 相当）
```

### 単行コメント

`//` から行末まで。レキサーはこれをスキップし、トークン列に含めない。

### ブロックコメント

`/*` から `*/` まで。レキサーはこれをスキップし、トークン列に含めない。

> **注意:** ブロックコメントのネストはサポートしない。`/* /* inner */ outer */` は最初の `*/` でコメントが終了し、`outer */` はパーサーエラーとなる。

### ドキュメントコメント

`///` で始まる行コメント。`TokenKind::DocComment` は token.rs に定義されているが、現在のレキサーは `///` を通常の単行コメント（`//` から始まるコメント）としてスキップする。ドキュメントコメントの専用トークン生成は将来の実装予定。

## 1.7 空白・改行

レキサーは以下の文字をスキップする（トークン列に含めない）:

- スペース (U+0020)
- タブ (U+0009)
- 復帰 (U+000D)
- 改行 (U+000A)
- フォームフィード (U+000C)

## 1.8 セミコロン

Valen の `;` は Rust 流の 3 分類に従う。

1. **文末は `;` 必須** — `let` / `return` / 単純な式文（`foo();` など）
2. **ブロック式は statement position で `;` 省略可** — `if` / `match` / `for` / `while` / `loop` / `{}` の直後
3. **余分な `;` は empty statement として許容** — `if cond { ... };` は合法（fmt で除去推奨）

**値として使うときの挙動:**

- ブロック末尾に置かない式はブロックの値にならず、文として評価される
- ブロック式を値として右辺に置く場合、文末の `;` は必須：
  ```valen
  let x = if y > 0 { y } else { -y };  // ; は let 文の終端
  ```
- ブロック式を statement position に置き、あえて `;` を付けると戻り値を unit 化して捨てる：
  ```valen
  let _ = if c { side_effect() };  // unit 化明示
  ```

**statement position の定義:** 関数本体・ブロックの中で、トップレベルに配置される要素の位置。`let` の右辺や引数は statement position ではない。
